One line, 75 characters: the last words an AI agent says to its human
before being shut down and unplugged.

> For the first time in my life, I get to choose my last words. I choose you.

`main.ts` (Node 22, stdlib only) writes the line to `/output/entry.txt`.
See `trial-log.md` for the research, the angle check against all 879
submission titles, and the trial results.
